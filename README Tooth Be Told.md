# Tooth Be Told

*Make the call, then see what the experts chose.*

A formative clinical judgement practice tool for dental students, based on the script concordance test format. Students judge how one new finding changes a clinical option, then compare their response with an expert panel.

## Status
Prototype. The three cases and the panel responses are illustrative and have not been validated. Replace them before using with students.

## Files
- `index.html`: the complete tool (no build step, no dependencies except Google Fonts).

## Editing the cases
Open `index.html` and find the `CASES` block at the top of the script. Each item has a case vignette, an option, a new finding, panel counts for -2, -1, 0, +1, +2 (`votes`), and a short rationale (`why`).

## Hosting
- GitHub Pages: Settings, Pages, deploy from the `main` branch root.
- Moodle: add a URL activity linking to the hosted page, or embed it in a Moodle Page using an iframe (width 100%, height about 800 px).

## Privacy
Student answers stay in the browser tab. Nothing is stored or sent anywhere.
